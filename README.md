# 🚀 TechExplore

TechExplore is a modern, responsive website for an online tech learning platform. It lets visitors browse tech courses, meet instructors, read student testimonials, and get in touch. The site uses smooth animations and a dark theme.


## ✨ Features

- **Hero Section**: an animated landing banner with a call to action
- **Featured Courses**: courses shown as interactive cards with a hover effect
- **Courses Page**: all courses in 3D tilt cards, loaded from a JSON data file
- **Why Choose Us**: a scroll-reveal section that highlights the platform's strengths
- **Instructors**: instructor profiles with animated tooltips
- **Student Testimonials**: infinite moving review cards
- **Contact Page**: a contact form with a full-screen meteor animation
- **Responsive Design**: works on mobile, tablet and desktop
- **Dark UI**: a modern black theme with glowing effects

> The animated effects on this site (3D cards, spotlight, meteors, moving cards and more) are built with components from [Aceternity UI](https://ui.aceternity.com/).
